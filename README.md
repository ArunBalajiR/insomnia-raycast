# Insomnia

A Raycast extension to control [Insomnia](https://github.com/...) awake sessions using its built-in `--session` CLI.

## Commands

- **Start Awake Session** – pick a duration preset to start a timed session.
- **Extend Awake Session** – add time to the active session.
- **End Awake Session** – end the current session and release power locks.
- **Insomnia Status** – check whether a session is running.

## Requirements

- macOS with the Insomnia app installed at `~/Applications/Insomnia.app` (or `/Applications/Insomnia.app`).

## Development

```bash
npm install
npm run dev
```
